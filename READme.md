# Assignment: Responsive Task

## Overview
This project is a high-fidelity landing page clone of the "Two Leaves and a Bud" website. The primary objective was to master modern CSS layout techniques, implement responsive design, and create premium micro-interactions—all while building a robust foundation for future integration into a MERN stack application.

---

## Features

### Fully Responsive Design
The layout automatically adjusts from a desktop view to tablet and mobile screens using CSS media queries.

### Complex CSS Layouts
- Implemented CSS Grid for product catalogs.
- Used Flexbox for hero and partner sections.
- Maintained a clean and scalable structure.

### Premium Animations
- Used `@keyframes` for smooth cinematic entrance animations.
- Added breathing background effects for high visual engagement.
- Implemented sophisticated hover states and transitions for a premium feel.

### Performance-Focused
- Optimized for quick loading.
- Used CDN-hosted icons for better performance.
- Structured CSS for maintainability and scalability.

---

## Technologies Used

- **HTML5** — Semantic markup for proper structure.
- **CSS3** — Custom styling, Flexbox, Grid, and responsive media queries.
- **Remix Icons** — Lightweight and modern icon library.
- **Google Fonts** — Using *Lora* and *Work Sans* for authentic typography.
